
# 🚦 Smart Traffic Management System for Emission Reduction

AI-powered Smart Traffic Management System designed to optimize traffic signal timing using real-time vehicle detection and adaptive decision-making. The system reduces traffic congestion, waiting time, and carbon emissions using computer vision and machine learning.

---

## 📌 Project Overview

This project uses Artificial Intelligence and Computer Vision to analyze live traffic conditions and dynamically control traffic signals. Instead of fixed-timer signals, the system calculates traffic density and adjusts signals intelligently to improve flow efficiency.

Key goals:

✅ Reduce traffic congestion  
✅ Minimize idle vehicle emissions  
✅ Improve signal efficiency  
✅ Support smart city infrastructure  

---

## 🧠 Features

- Real-time vehicle detection using YOLOv8
- Multi-class vehicle classification (car, bus, truck, motorcycle)
- AI-based signal priority calculation
- Emission-aware traffic optimization
- Interactive Gradio dashboard
- Modern responsive frontend UI

## ⚙️ How It Works

1. Video stream is analyzed using YOLOv8.
2. Vehicles are detected and classified.
3. Traffic density and priority score calculated.
4. Signal timing adjusted dynamically.
5. CO₂ emission reduction estimated based on idling time.
